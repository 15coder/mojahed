# مولّد كود التفعيل — مجاهد للتجارة
## License Key Generator — Mujahid Trading

---

## المواصفات التقنية الدقيقة (لضمان التوافق الكامل)

| المعامل | القيمة |
|---------|--------|
| **الخوارزمية** | RSA — PKCS#1 v1.5 |
| **حجم المفتاح** | 2048-bit |
| **دالة الهاش** | SHA-256 |
| **مكتبة التطبيق (Client)** | `node-forge` (أحدث إصدار) |
| **مكتبة الكيجن (Node.js)** | `crypto` (مدمجة مع Node.js — لا تحتاج تثبيت) |
| **ترميز التوقيع** | Base64 |
| **تنسيق كود التفعيل للعميل** | Base64 مقسّم كل 4 أحرف بشرطة `-` |

---

## آلية عمل النظام

```
[جهاز العميل]
    │
    ├── HWID = ANDROID_ID أو identifierForVendor
    ├── raw_hwid = HWID.trim().toLowerCase()
    ├── كود الطلب = أول 20 حرف من SHA256(raw_hwid) بالأحرف الكبيرة، مقسّمة XXXX-XXXX-XXXX-XXXX-XXXX
    │
    └── يرسل كود الطلب للمطور

[المطور — الكيجن]
    │
    ├── clean_code = كود الطلب بدون شرطات، بالأحرف الصغيرة
    ├── التوقيع = RSA-PKCS1v1.5-SHA256(private_key, clean_code)
    └── كود التفعيل = Base64(التوقيع) مقسّم كل 4 أحرف بشرطة

[جهاز العميل — التحقق]
    │
    ├── clean_sig = كود التفعيل بدون شرطات
    ├── sig_bytes = Base64Decode(clean_sig)
    ├── hwid = getHWID() (نفس العملية السابقة)
    └── RSA_Verify(public_key, hwid, sig_bytes, SHA256) → true/false
```

## الاستخدام

### 1. تأكد من وجود ملف `private.key` في نفس المجلد

### 2. شغّل الكيجن:
```bash
node keygen.js XXXX-XXXX-XXXX-XXXX-XXXX
```

### مثال:
```bash
node keygen.js A3F2-9B1C-7E4D-2A8F-6C5B
```

```
✅ كود التفعيل:

[كود طويل بتنسيق BASE64 مجمّع بشرطات]
```

## تنسيق البيانات المتبادلة بين التطبيقين

### كود الطلب (من العميل للمطور):
- **20 حرفاً** من SHA-256 (أول 20 حرف من الـ hex)
- **أحرف كبيرة** مقسّمة إلى 5 مجموعات من 4
- **مثال**: `A3F2-9B1C-7E4D-2A8F-6C5B`

### معالجة الكيجن:
1. احذف الشرطات: `A3F29B1C7E4D2A8F6C5B`
2. حوّل لأحرف صغيرة: `a3f29b1c7e4d2a8f6c5b`
3. وقّع: `RSA_PKCS1v1.5_SHA256(private_key, "a3f29b1c7e4d2a8f6c5b")`
4. حوّل لـ Base64 وقسّم كل 4 أحرف بشرطة

### كود التفعيل (من المطور للعميل):
- توقيع RSA كامل (344+ حرف Base64) مقسّم بشرطات
- العميل يحذف الشرطات تلقائياً عند التحقق
